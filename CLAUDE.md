# CLAUDE.md — Battlecard

BattleCard — customizable battle card builder with game icons + PNG export (battlecard.neorgon.com)

**Live:** battlecard.neorgon.com · **Port:** 8823

## Run

```bash
make serve
```

Then open http://localhost:8823. It must be served over HTTP — the app is ES modules, and `file://` blocks them.

## Architecture

| Module | Lines | Owns |
|---|---:|---|
| `js/events.js` | 417 | `bindEvents` |
| `js/render.js` | 267 | `renderAll`, `renderIconModal`, `renderLayoutModal`, `renderThemePicker`, `applyTheme` |
| `js/state.js` | 188 | `normalizeCard`, `state`, `saveState`, `replaceState`, `resetState` |
| `js/templates.js` | 141 | `TEMPLATES` |
| `js/export.js` | 113 | `exportJSON`, `importJSONFile`, `copyShareLink`, `exportPNG`, `exportView` |
| `js/icons.js` | 96 | `THEMES`, `ICONS`, `ACCENT_COLORS`, `iconHtml`, `chromeIconHtml` |
| `js/utils.js` | 21 | `toast`, `escHtml` |
| `js/app.js` | 14 | — |

Vendored from `packages/neorgon-ui/` — never edit in place, run the sync script instead: `js/neorgon-footer.js`, `js/neorgon-header.js`.

## Data

- `localStorage['battlecard-v1']`

## Conventions

- Zero build step. Plain ES modules loaded by `js/app.js`.
- Header and footer come from the shared kits. Do not add site-local `.neo-footer` or `.header-bar` CSS.
- No single JS file over ~500 lines. It currently holds.
